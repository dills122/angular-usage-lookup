# Paired blind discovery qualification

**Final rebuilt-ZIP trial passed on 2026-10-14:** all 36 physical sites, 84
site/config pairs and eight leaf configs matched, with independently checked
native evidence and unchanged application/installed-helper files. Five completed
blind runs are retained; every run matched the positive location/context oracle,
while earlier incomplete evidence and coverage outcomes remain visible.

This evaluation exercises independent scope/probe/candidate discovery using the
actual installed skill ZIP. It complements the earlier large component/dialog
trial and deterministic Material/version/scale suites. It does not measure a
universal production accuracy percentage.

## Fixture and blinding

Two source-authored Nx workspaces contain three requested targets: a generic
custom component, Material `MatOption`, and `MatTreeNodePadding`. Each has four
projects, eight leaf configs, 36 active physical template sites and 84 site/config
pairs. Each target contributes 12 sites and 28 pairs.

The second variant renames the custom class/selectors, introduces barrel and
consumer aliases, relocates projects, moves main templates to external files
with spaces in their names, and adds CRLF/UTF-16 controls. Both retain tests and
stories importing main owners transitively, same-selector decoys, comments,
ordinary strings and non-bindable descendants. Stable logical IDs and config
roles are authored before backend queries. Both variants compile all eight Nx
targets; deterministic tests verify their equivalent Angular associations.

Each trial uses a fresh agent with no parent history, an extracted ZIP, physical
dependency copies and public target identities. There are no prepared manifests,
probes, candidate anchors or oracle files in its inputs. Private grading remains
outside the input. Isolation is instruction-level, not enforced by a separate
filesystem. This evaluates explicitly invoked skill use, not automatic selection.

## First submissions

Both independently recovered all 36 physical sites and all 84 config associations,
with no missing or extra locations/contexts against the unchanged private oracle.
They excluded comments, strings, unrelated scoped declarations and non-bindable
descendants, retaining raw positive semantic associations for the latter.

Both found that the collector rejected main owners imported transitively by
spec/story roots. They independently reused the shipped compiler adapter directly
for exact-program associations and retained the rejected collector attempts.
Neither edited application or installed helper files.

The baseline submission supplies complete linked hash/config/native evidence and
passes the mechanical grader. The transformed submission reports partial
coverage for its two target-free libraries. Its direct compiler reports also omit
config/source hashes and opening-tag end offsets required for strict linked
evidence grading. Its location/context match is preserved, but it does not earn
a full evidence/coverage pass. The grader does not turn correct counts into proof.

The first transformed agent disclosed an accidental read of existing `.nx` cache
files during an initial broad read. These were generated by compilation, not
answer keys; the run still has imperfect input isolation. Rerun preparation
removes those caches before dispatch.

## Defects fixed

The explicit compiler candidate path now accepts transitive owners only when
they belong to the requested compiler program and Angular maps the requested
source node to that owner and exact target declaration. It records config path,
hash, roots and program membership independently of Language Service project
selection. Default Language Service ownership checks remain in place.

Regression tests first reproduced the root-only rejection, then verified inline
and external templates under both spec and story configs. Foreign-program owners
and incorrect external-template owners stay unresolved. Compiler recoveries do
not modify raw reference arrays. Source files and child-process cleanup are checked.

The initial grader also trusted successful-looking flags and nonempty definitions.
Adversarial regressions now require exact native destinations/spans, independent
TypeScript target identity and config/program membership, source/config hashes,
and linked coverage for target-free configs. Failed or partial scope cannot pass
because its filenames and counts happen to match.

The first rerun also exposed Nx discovery creating `.nx` database/graph files.
Discovery now directs Nx caches, Node compile caches and child-process temporary
files into one isolated OS scratch directory and removes it in `finally`. Tests
first reproduced writes in clean, pre-cached and failing-plugin workspaces, then
verified exact directory/hash preservation and temporary cleanup in all three.
Final review also identified inherited temporary roots inside the workspace.
Discovery canonicalizes the temporary root and rejects workspace-equal,
descendant and symlinked-descendant paths before creating anything. Three more
regressions cover those refusals. The in-progress final trial was stopped before
submission when this guard was added; its partial output is retained, and it is
not counted as a completed or passed run.

## First rerun

Fresh agents using the rebuilt ZIP again found all 36 sites and 84 context pairs
in each variant. The baseline supplied complete native proof and passed grading.
The transformed report remained partial for its target-free component library;
its direct-adapter query records lacked per-query source hashes, so linked native
evidence grading also remains unsuccessful. The report retained source hashes
elsewhere, but the grader does not silently substitute unrelated evidence links.

Native evidence can be wrapped in different JSON layouts. The grader now accepts
both direct records and unchanged native query responses with their hashes and
config proof; format support has positive and negative regressions. Correct
baseline evidence is not rejected merely because `config` is an object or the
native response lives under `queries[].response`.

The baseline agent disclosed the `.nx` write, which prompted the second production
fix above. A final fresh trial uses the rebuilt ZIP and a clarified evidence
serialization contract; no counts, probes or candidate locations are supplied.

## Final rebuilt-ZIP trial

The transformed-r4 agent used the final ZIP, discovered its own scope/probes and
candidates, and passed exact inventory, linked native evidence, configuration
coverage and source-integrity grading. Each of the three targets has 12 active
physical sites and 28 config associations, with no misses or extras. It verified
both target-free libraries through exact compiler programs, native associations,
compilation and projection-only-template inspection. Four foreign decoy nodes
and six inactive non-bindable descendants were correctly excluded.

All 33 application/config files and every installed ZIP payload file were
unchanged. No workspace `.nx` cache was created. The original transformed oracle
checksum is unchanged. The final report investigates eight peculiar groups:
four recovered omissions/context gaps and four explained cases, with no pending
or unresolved static-scope item. Runtime execution remains outside the claim.

The final trial's evidence envelope was specified in the request so that the
grader could validate native responses consistently. This clarified serialization,
not discovery: no expected locations, counts, configs, probes or hints were given.
Earlier incomplete transformed submissions retain failed evidence/coverage grades;
their reports and the original oracle expectations were not changed.

## Reproduction and limits

Local validation passed: 64 ordinary tests/subtests, 57 transformation/grading
tests plus six preparation tests, the rendering gauntlet, both 54- and 102-library
Nx scale profiles, all 183 Material checks, both isolated Angular 20/22 profiles,
ten packaging regressions, repository validation and extracted-ZIP smoke tests.
The six discovery read-only cases are included in the ordinary total. Read-only
reviews covered the production changes and fixture/preparation/CI flow; the
temporary-root finding was fixed and the review closed. These are local results,
not a claim about an unrun hosted CI job.

Use the [paired trial procedure](agent-evaluation.md#paired-blind-discovery-and-transformations).
`npm run test:blind` runs deterministic transformations and grader controls in CI;
fresh-agent trials remain a manual behavioral gate. Full local artifacts are
retained in `/private/tmp/angular-blind-{baseline,transformed}-r{1,2}` and
`/private/tmp/angular-blind-transformed-r4`, with separate private grading
directories. These temporary paths are not durable release assets.
[Machine-readable metrics](blind-discovery-metrics.json) retain checksums, exact
per-target matches and separate evidence/scope outcomes for the preserved runs.

The fixtures cover static template sites, not runtime instantiation, browser
interaction, real Jest/Storybook execution, federation, published-library builds,
all input/output combinations or every Angular version. The compiler adapter is
still qualified only for Angular 21.2.25. Honest partial scope remains partial;
no expectation is removed to improve a score.
